# gitar-demo

Main Application: This is a small backend(flask API) that stores items with titles and tags, and lets you search and remove them — the kind of generic building block a lot of apps have somewhere. Users create items, tag them for organization, search by keyword, and remove them when done. Nothing exotic — the kind of small service every product has a dozen of.


PR Request: when someone adds tags to an item, we want to make sure duplicate tags don't sneak in — if you tag something "urgent" twice, it should only show up once. A small, reasonable usability fix.
